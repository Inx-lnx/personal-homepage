背景音乐说明
================

本目录已内置一首原创纯音乐（钢琴 + 小提琴同时演奏）：

    bgm.mp3    约 2 分 13 秒 / 2.5 MB / 160 kbps

调性 A 小调（B 段转都节调式），60 BPM。
音色是**真实乐器采样**，不是合成音色 —— MIDI 谱经 FluidSynth +
MuseScore_General.sf3（真实钢琴 / 小提琴录音采样，MIT 授权）渲染，
再用自建卷积残响收尾。重新生成：

    python tools/make_bgm_sampled.py

（早期自研的加性合成版仍保留，作为不依赖外部音源的回退方案：
  python tools/make_bgm.py）

  [钢琴]  真实钢琴采样。泛音之间带着 -57 dB 的琴体与房间噪声
          （合成版那里是 -148 dB 的数字静音，这正是「电子感」的来源），
          每个音的泛音有真实拍音与起伏，非谐波成分 0.03%。
          整曲频谱重心 1394 Hz、琴身频段（200~800 Hz）占比 93.4%，
          比合成版更暖、没有高频亮刺。

  [小提琴] 真实小提琴采样，第五层长弓铺底（圆号音色号 program 40）：
          **从第 0 小节就与钢琴同时进入**，全程 30 处换音、两处 8 拍长音
          跨过段落交界（第 11、27 小节），音区锁在 G3~E4（196~330 Hz），
          在钢琴旋律（A4~A5）下方一个八度，填满留白却不遮旋律。
          客观验证：有声占比 100.0%、静音空洞 0 个。
          电平：比旋律层低 5.5 dB（真实小提琴是持续音，峰值因数只有
          13.8 dB，同样的 RMS 会显得更响，所以配比是按实测重新定的）。

  [悠扬]  音与音之间不再断成一颗一颗：旋律 / 伴奏 / 钟声的松键余量分别多留
          +1.6 / +1.0 / +0.45 秒，音尾互相叠进彼此的残响；
          自建卷积残响（2.8 s、预延迟 30 ms、湿声 34%）+ 温和倾斜
          （900 Hz 以上每倍频程 +0.8 dB，上限 +3 dB；8 kHz 以上收掉）；
          结尾 3.5 s 渐弱、开头 12 ms 淡入。
          客观验证：有声占比 100.0%、乐曲主体里的静音空洞 0 个（全程不断线）。

  [东方配乐色彩] 挂留和弦 sus2/sus4 的空旷悬置感；
                  A/B/A' 段贯穿的钟声式重复动机（A5 / E5 交替）。

  [物哀 · 缥缈]  都节调式的小二度阴翳、句尾下行叹息、
                  大幅留白（旋律稀疏 + 伴奏改四分音符）、
                  温和的频谱倾斜（不刺耳、也不糊）、结尾缓慢消散。

旋律为原创，未使用任何既有作品的主题旋律，可安全用于公开页面。
（风格上参考了 Merry Christmas, Mr. Lawrence 那类曲目的织体手法，
  但只借用调式、和声色彩与织体，不引用其受版权保护的主题旋律。）

音源授权：渲染器 FluidSynth（LGPL）+ 音源 MuseScore_General.sf3
（MIT，S. Christian Collins 整理）。音源文件本身**不随本目录分发**，
这里只放渲染出来的 mp3。想重新生成，先自行下载这两样，再跑：

    python tools/make_bgm_sampled.py --sf <MuseScore_General.sf3 路径> --fs <fluidsynth.exe 路径>

想换成自己的音乐？
   把你自己的文件重命名为 bgm.mp3 覆盖它即可，不需要改代码。
   （不想覆盖原曲，就改 assets/config.js 里 music.src 的路径。）

------------------------------------------------------------
想用别的文件名？
------------------------------------------------------------
打开 assets/config.js，改 music.src 的值，例如：

    src: "assets/music/我的音乐.mp3"

------------------------------------------------------------
想调音量 / 彻底关掉背景音乐？
------------------------------------------------------------
同样在 assets/config.js 的 music 里：

    volume: 0.35     // 0 ~ 1，背景音乐建议不要超过 0.5
    enabled: false   // 整体关闭（右下角按钮和引导气泡都不出现）

------------------------------------------------------------
格式建议
------------------------------------------------------------
推荐 mp3：所有浏览器都支持、体积小。
也支持 .m4a / .ogg，但不同浏览器支持面不一致，优先用 mp3。

------------------------------------------------------------
注意事项
------------------------------------------------------------
1. 文件别太大
   背景音乐建议 1 ~ 5 MB，过大会拖慢首次加载。
   可用 ffmpeg 压缩：ffmpeg -i 原文件.mp3 -b:a 160k -ac 2 bgm.mp3

2. 版权
   请使用自己创作、已获授权或明确免费可商用的音乐。
   个人主页是对外公开的，这一点尤其要注意。

3. 关于自动播放
   浏览器禁止页面在「没有任何用户交互」时自动播放有声内容，
   所以这里的交互设计是：访客点右下角按钮 → 开始播放。
   开关状态会记在浏览器本地，下次进站会自动尝试续播。

4. 放好文件后刷新页面即可
   调试时可在浏览器控制台输入：
     __BGM.state()   // 查看当前状态：idle / playing / missing
     __BGM.play()    // 手动播放
     __BGM.pause()   // 手动暂停
